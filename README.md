# ATmega328P & STM32 Low-Power Systems

This repository contains my Advanced Embedded Systems assignment on
microcontroller low-power modes and interrupt-based wake-up mechanisms.

## Assignment Parts

### Part 1 — ATmega328P Sleep Mode
- Power-down mode
- Sleep Mode Control Register (SMCR)
- External Interrupt INT0
- EICRA and EIMSK configuration
- Interrupt-based wake-up
- Proteus simulation
- Embedded C implementation

### Part 2 — STM32 Research
- STM32 architecture
- Low-power modes
- Power-control and clock systems
- Wake-up sources
- WFI and WFE
- Important registers and interrupt mechanisms

### Part 3 — STM32 Presentation
**STM32 Low-Power Modes and Wake-Up Mechanisms**

## Main Objective

Demonstrate the complete embedded-systems workflow:

**Datasheet → Register Analysis → Circuit Design → Embedded C → Sleep Mode → Interrupt Wake-Up → Proteus Simulation**

The STM32 section is a separate research and presentation activity and
does not replace the ATmega328P Proteus implementation.
